A preview and engraving update. The preview pane can now be zoomed and scrolled sideways, and the music engraving engine (CeolKit) has been updated from 1.5.0 to 1.9.0, which draws chord symbols and annotations and fixes how stylesheet directives in a tune header are scoped.
  • The preview pane has a zoom control: zoom out, a level picker, and zoom in. The View menu has Zoom In (⌘+), Zoom Out (⌘−), Actual Size (⌘0) and Fit Width. Zoom runs from 50% to 400%, is set per window, and is kept when a window is restored. The same point of the score stays centered when the zoom changes.
  • The preview now scrolls horizontally when the pages are wider than the pane. Before, anything past the right edge could not be reached.
  • Chord symbols ("Am7") and annotations ("^text", "_text", "<text", ">text", "@x,y text") are now drawn. Before, they were read but not printed.
  • Quoted text that is not a chord, such as "Fine" or "D.C. al Fine", is printed on the chord line as written, with a warning suggesting "^…". Quoted text written before a grace group, as in "^text"{g}A, goes to the main note and is no longer lost.
  • A variant ending that starts part way through a bar has its bracket start at its first note instead of at the bar line.
  • Stylesheet directives in a tune header now apply to that tune only. Before, %%ceolkit:scale, %%ceolkit:gracenotespacing, %%pipeformat, %%ceolkit:justifylast, %%straightflags and %%graceslurs carried on into later tunes, or were ignored after the first tune. A document that relied on this needs the directive moved to the file header.
  • %%footer in a tune header applies to that tune. A page prints the footer of the tune whose music starts it. Before, the last footer in the file was printed on every page.
  • A %%score or %%staves in the file header now applies to every tune, not only the first.
  • %%landscape can change the page orientation part way through a document when it is written together with a %%newpage. Without one it is ignored, with a warning.
  • New %%ceolkit:label "text" directive supplies the text of a ${label} mark in a %%footer, such as the name of a section. In the file header it covers the document; in a tune header it covers that tune.
