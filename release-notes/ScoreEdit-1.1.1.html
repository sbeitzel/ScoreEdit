A small fix to how the preview asks for permission to read included files. Editing, engraving (CeolKit 1.2.1), and everything else are unchanged from 1.1.0.
  • The “grant access” banner above the preview now goes away once the I:abc-include line stops naming the file it was asking about. Typing an include path slowly used to leave a banner behind for each half-finished name the preview happened to catch mid-keystroke — asking for permission to read files that were never referred to, and often did not exist — and those rows stayed until the window was closed.
