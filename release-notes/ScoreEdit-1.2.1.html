An engraving update. The music engraving engine (CeolKit) has been updated from 1.3.0 to 1.5.0, which fixes page breaks, page numbering, footers, percent signs in text fields, and I: directives in headers. The editor, preview, and include handling are unchanged from 1.2.0.
  • %%newpage now starts a new page, as it does in abcm2ps. Where it appears decides what moves: in the file header it moves the first tune, between tunes it moves the tune below it, in a tune header it moves that tune, and in a tune body it moves the stave below it. A break in the middle of a stave moves back to the start of that stave, with a warning. %%newpage N also renumbers the page it starts.
  • %%ceolkit:pagenumber N now sets the first page number. Before, the directive was accepted and then ignored, so every document started at page 1. It works together with %%newpage N.
  • A %%footer template can use ${pagenumber}, ${pagecount}, ${title} and ${date}.
  • A $ placeholder in a %%footer that the engine does not substitute now gets a warning in the gutter. Before, it was printed on the page as literal text. The $Q placeholder has been removed; it never worked.
  • \% in a text field is a literal percent sign, so T:100\% Pipes is no longer cut off at 100\. \\ is a single backslash.
  • I: stylesheet directives in the file header or a tune header now work the same way as their %% form. Before, they were ignored with no warning, so a file that contains one may look different now.
  • A line with nothing but %% is treated as a comment and no longer shows an “Unsupported stylesheet directive” warning.
