A rendering-quality update. The music engraving engine (CeolKit) has been updated to 1.2.1, which fixes a number of layout and spacing problems and adds two directives for controlling how a tune is drawn. Editing, preview, and file inclusion are unchanged.
  • Engraving now follows the SMuFL 1.4 metadata's own engraving defaults (stem thickness, barline weights, staff line thickness, and so on) instead of approximating them, and ships the updated Bravura 1.392 music font.
  • Text in the preview is emitted as outlines, so titles, composer lines, and lyrics render identically no matter which fonts are installed.
  • Line breaking no longer strands a single measure on the last line and stretches it across the full page width; systems are balanced when a stave has to be split.
  • Staff lines now run through to the end of a line-ending ||, and bar lines shared between measures are no longer drawn twice.
  • Accidentals are positioned from the actual width of the glyph being drawn, correcting spacing that was noticeably off for some accidental/notehead pairs.
  • Grace-note groups are spaced more tightly, so densely embellished settings fit as intended.
  • New %%ceolkit:scale <factor> directive scales a single tune relative to the default size — for example %%ceolkit:scale 0.8 renders it at 80%, useful for fitting a long tune on one page.
  • New %%ceolkit:gracenotespacing <factor> directive controls the spacing between grace notes within a group, per tune.
  • Every measure now carries an accurate source range, improving the accuracy of synchronized scrolling between the editor and the preview.
